# Второй мозг для Claude

Шаблон рабочей базы знаний, которую ведёт ИИ. Это обычные Markdown-файлы: человек читает их в [Obsidian](https://obsidian.md), а [Claude Code](https://claude.com/claude-code) пишет в те же файлы по правилам из `CLAUDE.md`.

Вы просто говорите Claude «закинь в мозг: …», а он сам решает, в какую заметку это положить, расставляет ссылки и коммитит изменения в git.

## Об авторе
Это моя разработка: я сам каждый день веду рабочую базу знаний по этой схеме, и она питает мою утреннюю сводку и личный дашборд в Claude.
В репозитории лежит именно **шаблон**: структура, правила для Claude и шаблоны заметок, без моих данных. Его можно и нужно настраивать под себя: переименовывайте разделы, добавляйте свои, меняйте правила в `CLAUDE.md` и шаблоны заметок. Claude будет работать по той версии правил, которую вы запишете.

— [R00tPengu1n](https://github.com/R00tPengu1n)

## Зачем
У ИИ-ассистента нет памяти между сессиями. Второй мозг даёт ему постоянный контекст: ваши проекты, цели, клиентов, планы обучения. Чем дольше вы им пользуетесь, тем точнее становятся ответы, сводки и советы.

## Структура

```
00 Входящие/   всё новое и неразобранное
10 Проекты/    одна заметка на проект
20 Бизнес/     клиенты, заказы, идеи заработка
30 Контент/    каналы, аудитория, идеи для постов
40 Обучение/   курсы, конспекты, что изучить
90 Шаблоны/    шаблоны заметок
Главная.md     карта базы
CLAUDE.md      правила для Claude
```

## Как начать
1. Нажмите **Use this template** на GitHub и создайте **приватный** репозиторий. Там будут ваши рабочие данные.
2. Склонируйте его и откройте папку в Obsidian: «Открыть папку как хранилище».
3. Впишите о себе пару строк в раздел «Об авторе» в `CLAUDE.md`.
4. Запустите Claude Code в этой папке и скажите: «Заполни второй мозг: спрашивай меня по одному вопросу». Claude сам найдёт пробелы (`?`) и пройдётся по ним.
5. Удалите `10 Проекты/Пример проекта.md`, когда появятся свои проекты.

## Как настроить под себя
- **Разделы.** Папки с номерами можно переименовать, удалить или добавить новые (например, `50 Клиенты/`). Номера нужны только для порядка в списке. После изменений поправьте раздел «Структура» в `CLAUDE.md`.
- **Правила.** `CLAUDE.md` — это инструкция для Claude обычным текстом. Хотите, чтобы он писал по-английски, вёл журнал решений или не коммитил сам — просто допишите это.
- **Шаблоны.** Заметки в `90 Шаблоны/` работают и в Obsidian (плагин «Шаблоны»), и для Claude. Добавьте поля во frontmatter, и Claude начнёт их заполнять.

## Команды
Это обычные фразы в чате с Claude, а не специальный синтаксис.

| Фраза | Что произойдёт |
|---|---|
| «закинь в мозг: …» | Claude положит запись в нужный раздел или во «Входящие» |
| «разбери входящие» | разложит «Входящие» по разделам, допишет в существующие заметки и расставит ссылки |
| «что у меня по проекту X?» | ответит по заметке проекта |
| «заполни пробелы» | найдёт `?` в заметках и спросит по одному вопросу |

## Связка с утренней сводкой
Если у вас есть ежедневная задача Claude по расписанию (например, утренняя сводка с задачами и календарём), добавьте в её промпт шаг:

> Прочитай `Главная.md` и заметки в `10 Проекты` со статусом «в разработке». Если у проекта записан следующий шаг, а задачи на него нет — предложи её. Если во «Входящих» есть заметки — напомни их разобрать.

Тогда сводка будет знать не только список задач, но и зачем вы всё это делаете.

## Правила приватности
- Репозиторий с вашими данными должен быть **приватным**. Публичным делайте только шаблон.
- В `CLAUDE.md` прописан запрет хранить пароли, токены и ключи API. Claude записывает только, где они лежат.
